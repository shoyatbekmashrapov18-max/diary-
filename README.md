# Мой дневник

Дневник-календарь в стиле iOS: на каждый день можно оставить запись и отметить настроение.

## Что умеет
- Календарь месяца, неделя с понедельника, сегодняшний день выделен красным кружком
- Запись и настроение на каждый день (панель снизу, как в iOS)
- Счётчик дней подряд и записей за месяц
- Список последних записей
- Светлая и тёмная тема по настройке системы

## Файлы
- `index.html` — разметка страницы
- `style.css` — стили
- `app.js` — логика: календарь, записи, сохранение

Записи хранятся в `localStorage` браузера.

## Запуск
Открыть `index.html` в браузере или через расширение Live Server в VS Code.
