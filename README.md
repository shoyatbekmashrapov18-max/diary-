# Мой дневник

Личный дашборд-дневник для компьютера в стиле брутализма: серый, тёмно-синий и белый, жёсткие рамки, атмосфера ночного кабинета.

Есть баннер с фото, бегущая строка, фото-виджеты (`img/`) и портал в конце страницы, который ведёт на `presentation.html` (заготовка под презентацию нового продукта).

## Виджеты
- **Сейчас** — цифровые часы с перелистыванием цифр, аналоговый циферблат с плавными стрелками, прогресс дня, месяца и года
- **Статистика** — дней подряд 🔥, записей за месяц, среднее настроение, встречи на неделю
- **Ближайшие встречи** — с обратным отсчётом («через 25 мин», «завтра, 10:00») и пометкой «сейчас»
- **Календарь** — настроение и цветные точки встреч на каждом дне, листание стрелками
- **День** — настроение, запись с автосохранением, список встреч и дел с галочками, добавление встречи с цветом
- **Настроение за 30 дней** — плавный график с подсказками при наведении
- **Последние записи** — с поиском и подсветкой найденного

## Фишки
- Тёмная тема «ночной кабинет» и светлая «бетон и бумага» (кнопка ◐)
- Координаты курсора в углу, параллакс главного фото, «взрыв» эмодзи при выборе настроения
- Портал: камера влетает в коридор внутри статуи и переходит на страницу презентации
- Горячие клавиши: `/` — поиск, `←` `→` — месяцы, `T` — сегодня, `Esc` — выйти из поля
- Экспорт и импорт резервной копии в JSON
- Уважает системную настройку «уменьшить движение»

## Файлы
- `index.html` — разметка
- `style.css` — стили и анимации
- `app.js` — логика: часы, календарь, записи, встречи, график

Записи и встречи хранятся в `localStorage` браузера — делайте «Экспорт», чтобы не потерять их.

## Запуск
Открыть `index.html` в браузере или через расширение Live Server в VS Code.
